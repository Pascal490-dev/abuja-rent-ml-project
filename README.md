# Abuja Apartment Rent Predictor

My machine learning project I used 400 made-up Abuja apartments to predict yearly rent and classify apartments as Expensive or Affordable.

## What is in this repository,
'Pascal_abuja_rent_project.ipynb' : my notebook with all the code, charts and answers
'abuja_apartment_400.csv' : the dataset

## What I Did
-  Explored the data and drew charts,
- Trained a Linear Regression model to predict rent (MAE: ₦171,685.32, R²: 89.73%),
- Trained a Decision Tree to classify apartments (accuracy: 77.5%),
- Compared different tree depths to understand overfitting

## What I Learned
- Data cleaning and preparation.
- Regression and classification.
- Model evaluation.
- Overfitting in machine learning.
